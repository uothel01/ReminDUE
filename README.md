# ReminDUE v1.2.1

Before it’s due, we remind you.

## v1.2.1 focus
- Fixed navigation so Calendar and Insights work reliably.
- Calendar supports month navigation and clickable dates.
- Maintenance is a supported item type.
- Confirmation is required for updates, deletes, imports, completion/payment.
- Completion/payment requires actual completion date and mandatory notes.
- Recurring completion preserves the completed occurrence and creates the next one.
- Insights replaces All Items and groups by type, category, date or status.
- Feedback is disabled until explicitly edited.
- Existing local storage key remains `remindue.items.v1`.

## Deploy
Replace the contents of the GitHub repository in one operation and make one commit. GitHub Pages then deploys the complete application together.

## Important
Before upgrading, use More → Export backup.
